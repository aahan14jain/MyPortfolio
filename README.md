# MyPortfolio

A clean, minimal single-page portfolio built with Next.js (App Router) and Tailwind CSS.

## Getting Started

First, install the dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Project Structure

- `app/page.tsx` - Main portfolio page with all sections
- `app/layout.tsx` - Root layout component
- `app/globals.css` - Global styles with Tailwind CSS

## Sections

The portfolio includes the following sections in order:
1. Navbar - Sticky navigation with smooth scroll links
2. Hero - Introduction section
3. About - Personal information
4. Skills - Technical skills grid
5. Projects - Project showcase with tags
6. Contact - Contact information
7. Footer - Footer with copyright

## Customization

Edit `app/page.tsx` to customize the content, including:
- Personal information in the Hero section
- About section text
- Skills and technologies
- Projects and descriptions
- Contact information
